# Sources — Bibliography

> Canonical URLs cited across the `references/` files. Venue policies change yearly — verify the current CFP before submitting.

## Recommended reading order

If a student only has a weekend to improve a paper draft, the highest-yield sequence is:

1. Current **target-venue CFP** and submission instructions
2. **MIT CommLab** planning / introduction / results pages
3. **Koopman** for the abstract
4. **Ernst** for message discipline
5. **Mensh and Kording** for whole-paper structure
6. **Shaw** for reviewer-style questions
7. Two or three **exemplar papers** from the exact target venue and topic family

That order best matches how real reviewers read drafts: first for fit and promise, then clarity, then evidence and novelty.
